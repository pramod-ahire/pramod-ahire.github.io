About

9.5 yrs · Pune, India

I'm a frontend and full-stack engineer in Pune, India, working on enterprise database management platforms. Most of my career has gone into one hard problem: making database infrastructure legible to the people who operate it — provisioning, telemetry, encryption, query performance — without the UI buckling under the volume of data behind it.

At EDB I lead the frontend for the EDB Postgres AI Console (formerly BigAnimal). That has meant architecting React at scale across a microservices monorepo, engineering real-time dashboards over WebSockets, and owning features end to end — including the Transparent Data Encryption UI, from problem discovery through production deployment.

Beyond product surface, I care about the infrastructure engineers build on. I designed EDB's feature-flag system on flagd / OpenFeature, migrating off a hosted SaaS to remove recurring licence cost and unblock on-premises customers, and filed a credited security advisory upstream while running it in production. More recently I built an MCP server exposing EDB database clusters to AI agents through a standardised tool interface.

The nine and a half years before that are the reason any of it works: a decade of component libraries, design systems, code review and mentoring, across healthcare portals, brand protection, fintech dashboards and augmented reality.
